# [Orchestrate Data Lifecycle Automation with Google Cloud Data Agents: Challenge Lab](https://partner.skills.google/catalog_lab/42042)

In this advanced challenge lab, you will act as a Lead Data Engineer for Cymbal Shops. Your goal is to modernize the company's data infrastructure by leveraging Google Cloud's specialized Data Agents to automate engineering, governance, and data science workflows. Instead of writing code from scratch, you will use natural language prompts to instruct agents to build production-grade Dataform pipelines, enforce strict Dataplex governance policies, and execute complex exploratory analysis in Colab Enterprise. This lab tests your ability to act as an "Agent Orchestrator," verifying that you can not only generate code but also troubleshoot, optimize, and govern it according to enterprise standards.
