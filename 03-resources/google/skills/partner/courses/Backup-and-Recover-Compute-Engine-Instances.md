# [Backup and Recover Compute Engine Instances](https://partner.skills.google/course_templates/935)

**Description:**

This skill badge course is designed to equip partners with proficiency in Google Cloud Backup and Disaster Recovery. Covering essential topics such as backup templates, Compute Engine instances, PostgreSQL databases, and featuring a practical challenge lab, the course provides a comprehensive and hands-on learning experience.

## Google Cloud Backup and Disaster Recovery Course

This skill badge course aims to provide hands-on expertise, guiding participants in mastering Google Cloud Backup and Disaster Recovery through labs covering backup templates, Compute Engine instances, PostgreSQL databases, and a challenge lab to test practical skills.
