# [Create and Test OCR and Forms Processors](https://partner.skills.google/course_templates/1719)

**Description:**

In this advanced challenge lab, you act as a technical developer implementing automated document processing workflows. Using the Document AI (DAI) API, you will solve a two-part challenge: extracting literary text from a novel and parsing structured data from medical forms. You will write Python scripts to handle synchronous online requests for small files and asynchronous batch processing for larger volumes. Beyond simple text extraction, you will leverage the Form Parser to identify complex key-value pairs and tabular data, converting unstructured PDFs into clean, actionable CSV datasets.
