# [Implement Automatic Disaster Recovery for Cloud SQL for PostgreSQL](https://partner.skills.google/course_templates/1151)

**Description:**

This course provides an in-depth exploration of automatic disaster recovery strategies for Google Cloud SQL for PostgreSQL. The course emphasizes creating highly available database environments, managing failovers, and recovering from simulated disasters. Through a challenge lab, you will gain hands-on experience in setting up high-availability instances, simulating disasters, and executing recovery processes to ensure continuous database availability.

## Implement Automatic Disaster Recovery for Cloud SQL for PostgreSQL

In this module, you will focus on implementing automatic disaster recovery for Cloud SQL for PostgreSQL. The challenge lab involves independently setting up a highly available Cloud SQL instance, simulating disaster scenarios, and managing failovers and recoveries. You will gain practical experience in ensuring database resilience through effective disaster recovery strategies.

### Lab - [Implement Automatic Disaster Recovery for Cloud SQL for PostgreSQL: Challenge Lab](https://partner.skills.google/course_templates/1151/labs/630207)

In this lab, you will set up a high availability (HA) Cloud SQL for PostgreSQL instance for DR and simulate an outage. The disaster recovery (DR) will include a regional fail-over and fallback process and a cascading cross-region fail-over employing Cloud SQL automated features.
