### Lab - [Modernize Legacy Data Warehouses with BigQuery Migration Service: Challenge Lab](https://partner.skills.google/course_templates/1594/labs/630184)

In this advanced challenge lab, you will act as a Lead Data Architect for Cymbal Bank. Your organization is undertaking a massive digital transformation, moving its core legacy data warehouse (simulated as an on-premises PostgreSQL/Oracle-compatible system) to Google Cloud's BigQuery. This is not a simple "lift and shift." You are tasked with re-architecting the data estate to leverage cloud-native capabilities. You must assess the migration complexity, design a schema evolution strategy using facades, implement a heterogeneous data pipeline using Database Migration Service (DMS) with AI-assisted schema conversion, and orchestrate the entire workflow with quality-gated pipelines.
