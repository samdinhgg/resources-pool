# [Configure Federated Spanner Connections with BigQuery](https://partner.skills.google/course_templates/1148)

**Description:**

This course delves into integrating Google Cloud Spanner with BigQuery to enhance your analytics capabilities. The course focuses on building a environment that extends your BigQuery-based analytics to access production data in Spanner. Through a challenge lab, you will gain hands-on experience in configuring federated connections to facilitate seamless data access and reporting.

## Configure Federated Spanner Connections with BigQuery

This module emphasizes the integration of Google Cloud Spanner with BigQuery. You will create a proof of concept environment where Spanner data can be accessed and analyzed through BigQuery. The module offers practical experience in setting up a Spanner environment, populating it with data using Dataflow, and establishing federated connections to enable seamless data queries and analytics.

### Lab - [Configure Federated Spanner Connections with BigQuery: Challenge Lab](https://partner.skills.google/course_templates/1148/labs/630181)

In this lab, the user is tasked with configuring a federated connection between BigQuery and a Spanner database. The lab involves setting up the connection, loading test data, and validating the integration by executing queries in BigQuery.
