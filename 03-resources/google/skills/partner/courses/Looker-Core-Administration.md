# [Looker Core Administration](https://partner.skills.google/course_templates/1733)

**Description:**

This course provides the basic understanding and skills to successfully implement and maintain a Looker Core instance in an enterprise environment. Topics covered include integration with GCP security, implementing group and user-based security, connecting data sources, primary Looker objects, performance tuning, and other fundamentals of Looker administration.
