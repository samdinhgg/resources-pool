# [Optimize Database Workloads on Google Cloud](https://partner.skills.google/course_templates/1090)

**Description:**

This Databases course consists of a series of advanced-level labs designed to validate your proficiency in migrating and managing Google Cloud databases. Each lab presents a set of the required tasks that you must complete with minimal assistance.

## Optimize Database Workloads on Google Cloud

This Databases course consists of a series of advanced-level labs designed to validate your proficiency in migrating and managing Google Cloud databases. Each lab presents a set of the required tasks that you must complete with minimal assistance.

### Lab - [[PTPPF]: Migrate an Amazon RDS Database to Cloud SQL for MySQL using Database Migration Service](https://partner.skills.google/course_templates/1090/labs/551902)

This lab focuses on moving an Amazon RDS database to Cloud SQL. You will need to configure the Database Migration Service to perform a continuous migration and create a Compute Engine instance and install MySQL client and Auth proxy, then connect to the database instance.

- [ ] [[PTPPF]: Migrate an Amazon RDS Database to Cloud SQL for MySQL using Database Migration Service](../labs/[PTPPF]-Migrate-an-Amazon-RDS-Database-to-Cloud-SQL-for-MySQL-using-Database-Migration-Service.md)

### Lab - [[PTPPF]: Migrate an Application from MySQL to Cloud Spanner](https://partner.skills.google/course_templates/1090/labs/551903)

This lab focuses on migrating a local MySQL database to Cloud Spanner for database modernization. You will need to use an open-source tool to do the schema conversion and data migration to Cloud Spanner from MySQL.

- [ ] [[PTPPF]: Migrate an Application from MySQL to Cloud Spanner](../labs/[PTPPF]-Migrate-an-Application-from-MySQL-to-Cloud-Spanner.md)

### Lab - [[PTPPF]: Migrate a PostgreSQL Database to AlloyDB for PostgreSQL](https://partner.skills.google/course_templates/1090/labs/551904)

This lab focuses on database migration to Google Cloud. You will need to use AlloyDB for PosgreSQL to accomplish database modernization for a demo application hosted on Cloud Run using PostgreSQL.

- [ ] [[PTPPF]: Migrate a PostgreSQL Database to AlloyDB for PostgreSQL](../labs/[PTPPF]-Migrate-a-PostgreSQL-Database-to-AlloyDB-for-PostgreSQL.md)

### Lab - [[PTPPF]: Build an Application with Memorystore for Redis](https://partner.skills.google/course_templates/1090/labs/551905)

This lab focuses on database migration to Google Cloud. You will need to use Memorystore for Redis to create a proof of concept for database modernization.

- [ ] [[PTPPF]: Build an Application with Memorystore for Redis](../labs/[PTPPF]-Build-an-Application-with-Memorystore-for-Redis.md)

### Lab - [[PTPPF]: Building Applications with Firestore](https://partner.skills.google/course_templates/1090/labs/551906)

This lab focuses on configuring Firestore as the backend database with realtime updates and offline persistence. You will need to use Cloud Firestore to accomplish database modernization in a application using Firebase Web version 8 SDK.

- [ ] [[PTPPF]: Building Applications with Firestore](../labs/[PTPPF]-Building-Applications-with-Firestore.md)

### Lab - [[PTPPF]: Migrating Apache Cassandra to Cloud Bigtable](https://partner.skills.google/course_templates/1090/labs/551907)

This lab focuses on Migrating Apache Cassandra to Cloud Bigtable using Dataflow. You will need to perform a database migration from Apache Cassandra to Bigtable using a Dataflow template.

- [ ] [[PTPPF]: Migrating Apache Cassandra to Cloud Bigtable](../labs/[PTPPF]-Migrating-Apache-Cassandra-to-Cloud-Bigtable.md)
