# [Migrate Redshift to BigQuery](https://partner.skills.google/course_templates/833)

**Description:**

This skill badge aims to evaluate a partners ability to utilize various methods available to them to migrate data from Redshift to BigQuery. Learners will perform the tasks of Migration from Redshift to BigQuery using the Data Transfer Service. Sample Data will be used during both methods. Learners will complete a challenge lab that focuses on the process of transferring both schema, data and SQL from a Redshift data warehouse to BigQuery.

## Migrate Redshift to BigQuery

This skill badge aims to evaluate a partners ability to utilize various methods available to them to migrate data from Redshift to BigQuery

### Lab - [Schema Migration to BigQuery](https://partner.skills.google/course_templates/833/labs/519387)

In this lab, you define schemas in BigQuery, create partitioned and cluster tables, and query nested and repeated fields.

- [ ] [Schema Migration to BigQuery](../labs/Schema-Migration-to-BigQuery.md)

### Lab - [Writing SQL for BigQuery](https://partner.skills.google/course_templates/833/labs/519388)

In this lab, you program SQL SELECT, INSERT, UPDATE, and DELETE statements to create and return data in BigQuery. You create tables and views using SQL DDL statements, and you create custom behaviors using user-defined functions (UDFs) and stored procedures.

- [ ] [Writing SQL for BigQuery](../labs/Writing-SQL-for-BigQuery.md)

### Lab - [Redshift to BigQuery Migration using Data Transfer Service](https://partner.skills.google/course_templates/833/labs/519389)

This lab instructs users on migration from AWS Redshift to BigQuery using the BigQuery Data Transfer Service and sample data. It walks you through the process of transferring both schema and data from an AWS Redshift data warehouse to BigQuery.

- [ ] [Redshift to BigQuery Migration using Data Transfer Service](../labs/Redshift-to-BigQuery-Migration-using-Data-Transfer-Service.md)

### Lab - [Redshift to BigQuery Migration using Data Transfer Service: Challenge Lab](https://partner.skills.google/course_templates/833/labs/519390)

This challenge lab will test user's proficiency on migration from AWS Redshift to BigQuery using the BigQuery Data Transfer Service and sample data. It will also test the user's knowledge of the process of transferring both schema and data from an AWS Redshift data warehouse to BigQuery.

- [ ] [Redshift to BigQuery Migration using Data Transfer Service: Challenge Lab](../labs/Redshift-to-BigQuery-Migration-using-Data-Transfer-Service-Challenge-Lab.md)
