# [Migrate Snowflake to BigQuery](https://partner.skills.google/course_templates/834)

**Description:**

This skill badge aims to evaluate a partner's ability to utilize various methods available to them to migrate data from Snowflake to BigQuery. Learners will perform various tasks in the labs included to learn SQL variances, understand schema design differences and tools available to perofrm migration when moving from Snowflake to BigQuery. Sample Data will be used during the labs. Learners will complete a challenge lab that focuses on the process of transferring both schema, data and SQL from a Snowflake data warehouse to BigQuery.
