# [Implement Manual Fail-over Testing with Bigtable](https://partner.skills.google/course_templates/1154)

**Description:**

This course offers an in-depth exploration of failover testing with Google Cloud Bigtable. The course focuses on building and managing a multi-cluster Bigtable environment, simulating regional failures, and implementing failover strategies. Through an intensive challenge lab, you'll gain hands-on experience in ensuring continuous application processing and maintaining data availability across different regions.

## Implement Manual Fail-over Testing with Bigtable

In this module, you will tackle practical failover testing techniques for Google Cloud Bigtable. You will build a multi-cluster setup, simulate regional failures, and configure failover mechanisms. This module provides hands-on experience in maintaining high availability and application continuity through manual failover testing, preparing you to manage critical database systems effectively in cloud environments.

### Lab - [Implement Manual Fail-over Testing with Bigtable: Challenge Lab](https://partner.skills.google/course_templates/1154/labs/504290)

In this lab, the user is tasked to build a Bigtable multi-cluster environment and test its failover capabilities by simulating a regional failure. The user will configure a secondary cluster in another region and ensure application processing seamlessly transitions to this backup cluster during the failure scenario.
