# [Build a Multi-Agent Campaign System with ADK and Agent Engine](https://partner.skills.google/course_templates/1726)

**Description:**

In this advanced challenge lab, you assume the role of an AI Engineer at Cymbal Group. You are tasked with building a sophisticated marketing automation system using the Agent Development Kit (ADK) and Model Context Protocol (MCP). You will develop a distributed network of specialized agents—Data Analysts, Researchers, and Financial Analysts—that communicate via Agent-to-Agent (A2A) messaging. By deploying these agents to Cloud Run and Vertex AI Agent Engine, you will create a seamless pipeline that transforms raw product briefs into localized, multimodal campaign JSON briefs.
