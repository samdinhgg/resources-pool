# [Export a BigQuery ML Model for Online Prediction](https://partner.skills.google/course_templates/1725)

**Description:**

In this advanced challenge lab, you act as an ML Engineer for Cymbal Group. Your task is to build a proof of concept for rapidly deploying machine learning solutions. You will use BigQuery ML to train a logistic regression model on astronomical data using GoogleSQL. Moving beyond training, you will export the model to Cloud Storage and deploy it to a Vertex AI endpoint to serve real-time online predictions and monitor for inference drift.
