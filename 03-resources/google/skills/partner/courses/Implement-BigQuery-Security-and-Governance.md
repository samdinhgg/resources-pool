# [Implement BigQuery Security and Governance](https://partner.skills.google/course_templates/1721)

**Description:**

In this advanced challenge lab, you step into the role of a Data Steward for Cymbal Bank. Your objective is to secure and govern sensitive customer data stored in BigQuery. You will configure precise dataset, row, and column level security, including dynamic data masking. Beyond access controls, you will use Dataplex to profile data, automate quality checks, and track lineage, while leveraging Cloud DLP to automatically classify and tag sensitive information.
