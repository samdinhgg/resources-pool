## Build AI/ML Models on Google Cloud

This Artificial Intelligence and Machine Learning module consists of a series of advanced-level labs designed to validate your proficiency in using AI and ML to extract, analyze, search, and store structured data from documents and improve customer service. Each lab presents a set of required tasks that you must complete with minimal assistance.

### Lab - [[PTPPF]: Build a Multi-Agent Campaign System with ADK and Agent Engine](https://partner.skills.google/course_templates/1087/labs/586152)

Design and deploy a multi-agent marketing system using ADK, Agent Engine, and MCP, featuring A2A communication, BigQuery integration, and sequential agent orchestration

- [ ] [[PTPPF]: Build a Multi-Agent Campaign System with ADK and Agent Engine](../labs/[PTPPF]-Build-a-Multi-Agent-Campaign-System-with-ADK-and-Agent-Engine.md)

### Lab - [[PTPPF]: Create and Test OCR and Forms Processors](https://partner.skills.google/course_templates/1087/labs/586153)

This lab focuses on extracting data from pdf documents and handwritten forms. You will need to use Python and Document AI APIs to perform Optical Character Recognition (OCR) on text and use Forms Processor to extract data and tables from the documents.

- [ ] [[PTPPF]: Create and Test OCR and Forms Processors](../labs/[PTPPF]-Create-and-Test-OCR-and-Forms-Processors.md)

### Lab - [[PTPPF]: Document AI Workbench - Custom Document Extractor](https://partner.skills.google/course_templates/1087/labs/586154)

This lab focuses on extracting and evaluating information from a document. You will need to create a Custom Document Extractor processor, identify and label text entities, and train a model to identify entity types within a document.

- [ ] [[PTPPF]: Document AI Workbench - Custom Document Extractor](../labs/[PTPPF]-Document-AI-Workbench-Custom-Document-Extractor.md)

### Lab - [[PTPPF]: Document AI Workbench - Uptraining](https://partner.skills.google/course_templates/1087/labs/586155)

This lab focuses on processing invoices. You will need to use the Invoice Parser to extract text and values from an invoice and train a model to process other invoices.

- [ ] [[PTPPF]: Document AI Workbench - Uptraining](../labs/[PTPPF]-Document-AI-Workbench-Uptraining.md)

### Lab - [[PTPPF]: Export a BigQuery ML Model for Online Prediction](https://partner.skills.google/course_templates/1087/labs/586156)

This lab focuses on deploying a BigQuery ML model on Vertex AI for online prediction. You will need to export a BigQuery model and then deploy the model on Vertex AI.

- [ ] [[PTPPF]: Export a BigQuery ML Model for Online Prediction](../labs/[PTPPF]-Export-a-BigQuery-ML-Model-for-Online-Prediction.md)

### Lab - [[PTPPF]: Train Custom ML Models on Vertex AI](https://partner.skills.google/course_templates/1087/labs/586157)

This lab focuses on training and deploying a custom model on Vertex AI for online prediction. You will need to use the Vertex AI SDK for Python to train and deploy a custom tabular classification model for online prediction.

- [ ] [[PTPPF]: Train Custom ML Models on Vertex AI](../labs/[PTPPF]-Train-Custom-ML-Models-on-Vertex-AI.md)

### Lab - [[PTPPF]: Tune Gemini Model by using Supervised Fine-tuning](https://partner.skills.google/course_templates/1087/labs/586158)

This lab focuses on supervised fine tuning with Gemini Model. You will need to use the Vertex AI to tune and deploy a Gemini model.

- [ ] [[PTPPF]: Tune Gemini Model by using Supervised Fine-tuning](../labs/[PTPPF]-Tune-Gemini-Model-by-using-Supervised-Fine-tuning.md)
