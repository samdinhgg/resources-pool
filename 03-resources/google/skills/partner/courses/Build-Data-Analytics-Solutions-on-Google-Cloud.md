## Build Data Analytics Solutions on Google Cloud

This Data Analytics module consists of a series of advanced-level labs designed to validate your proficiency in using Google Cloud services. Each lab presents a set of the required tasks that you must complete with minimal assistance.

### Lab - [[PTPPF]: Build a Data Warehouse / Data Lake](https://partner.skills.google/course_templates/1089/labs/612243)

This lab focuses building a Data Warehouse or Data Lake for analyzing data using BigQuery. You will need to extract data from BigQuery and create a report.

- [ ] [[PTPPF]: Build a Data Warehouse / Data Lake](../labs/[PTPPF]-Build-a-Data-Warehouse---Data-Lake.md)

### Lab - [[PTPPF]: Ingest Data into BigQuery](https://partner.skills.google/course_templates/1089/labs/612244)

This lab focuses on ingesting data from a sample legacy systems into BigQuery. You will need to develop a new analytic data warehouse using BigQuery and other Google Cloud services.

- [ ] [[PTPPF]: Ingest Data into BigQuery](../labs/[PTPPF]-Ingest-Data-into-BigQuery.md)

### Lab - [[PTPPF]: Implement BigQuery Security and Governance](https://partner.skills.google/course_templates/1089/labs/612245)

This lab focuses on maintaining customer data from a CRM system in MySQL. You will need to identify and secure sensitive data, make it discoverable, and finally build trust in the data.

- [ ] [[PTPPF]: Implement BigQuery Security and Governance](../labs/[PTPPF]-Implement-BigQuery-Security-and-Governance.md)

### Lab - [[PTPPF]: Create Real-time Data Processing Pipelines](https://partner.skills.google/course_templates/1089/labs/612246)

This lab focuses on creating a streaming an ingestion pipeline. You will need to develop and deploy a pipeline that can ingest streaming data, process it, and write the processed data to BigQuery.

- [ ] [[PTPPF]: Create Real-time Data Processing Pipelines](../labs/[PTPPF]-Create-Real-time-Data-Processing-Pipelines.md)

### Lab - [[PTPPF]: Build LookML Objects in Looker](https://partner.skills.google/course_templates/1089/labs/612247)

This lab focuses on building LookML objects in Looker. You will need to create different LookML objects to match a set of business requirements.

- [ ] [[PTPPF]: Build LookML Objects in Looker](../labs/[PTPPF]-Build-LookML-Objects-in-Looker.md)

### Lab - [[PTPPF]: Build a BI Dashboard Using Google Looker Studio and BigQuery](https://partner.skills.google/course_templates/1089/labs/612248)

In this lab, you build a BI dashboard with Looker Studio as the front end, powered by BigQuery on the back end.

- [ ] [[PTPPF]: Build a BI Dashboard Using Google Looker Studio and BigQuery](../labs/[PTPPF]-Build-a-BI-Dashboard-Using-Google-Looker-Studio-and-BigQuery.md)
