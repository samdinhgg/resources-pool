# [Automate Data Migrations to BigQuery](https://partner.skills.google/course_templates/825)

**Description:**

This skill badge aims to provide partners an introduction to BigQuery Data Transfer Service and Migration Service, two powerful tools for managing and migrating data in the cloud. Learners will learn how to leverage these tools to efficiently migrate and manage data, and gain hands-on experience through labs.

## Automate Data Migrations to BigQuery

In this course, you will work on labs that act as pre-requisite for any migration to BigQuery

### Lab - [Introduction to BigQuery Data Transfer Service](https://partner.skills.google/course_templates/825/labs/513707)

This lab guides the user to configure BigQuery Data Transfer Service job to automate data transfer from Cloud Storage to BigQuery.

- [ ] [Introduction to BigQuery Data Transfer Service](../labs/Introduction-to-BigQuery-Data-Transfer-Service.md)

### Lab - [Introduction to BigQuery SQL translation](https://partner.skills.google/course_templates/825/labs/513708)

In this lab, use the batch SQL translator in BigQuery to translate scripts written in other SQL dialects into GoogleSQL queries.

- [ ] [Introduction to BigQuery SQL translation](../labs/Introduction-to-BigQuery-SQL-translation.md)

### Lab - [Introduction to BigQuery Migration Service](https://partner.skills.google/course_templates/825/labs/513709)

This lab will demonstrate of migrating of data warehouse with Apache Hive database to BigQuery.

- [ ] [Introduction to BigQuery Migration Service](../labs/Introduction-to-BigQuery-Migration-Service.md)

### Lab - [BigQuery Migration Service Challenge Lab](https://partner.skills.google/course_templates/825/labs/513710)

This lab challenges user to migrate Apache Hive database to BigQuery.

- [ ] [BigQuery Migration Service Challenge Lab](../labs/BigQuery-Migration-Service-Challenge-Lab.md)
