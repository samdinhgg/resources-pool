# [Migrate Teradata to BigQuery](https://partner.skills.google/course_templates/835)

**Description:**

This skill badge aims to evaluate a partners ability to utilize various methods available to them to migrate data from Teradata to BigQuery. Learners will perform the tasks of Migration from Teradata to BigQuery using the Data Transfer Service and the Teradata TPT Export Utility. Sample Data will be used during both methods. Learners will complete a challenge lab that focuses on the process of transferring both schema, data and SQL from a Teradata data warehouse to BigQuery.
