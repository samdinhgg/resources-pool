# [Ingest Data into BigQuery](https://partner.skills.google/course_templates/1731)

**Description:**

In this advanced challenge lab, you act as a Data Engineer for Cymbal Superstore to build a modern analytical data warehouse. Your goal is to ingest data into BigQuery from various legacy systems and formats. You will create external tables linked to Cloud Storage, write stored procedures to clean and normalize messy text data, and set up real time streaming ingestion using Pub/Sub BigQuery Subscriptions. Finally, you will debug and configure a Java application to ingest data efficiently using the BigQuery Storage Write API.
