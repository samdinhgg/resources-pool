# [Configure Federated Connections for BigQuery and Cloud SQL for PostgreSQL](https://partner.skills.google/course_templates/1156)

**Description:**

This course explores the integration of Google BigQuery with Cloud SQL for PostgreSQL to enhance analytics capabilities. The course focuses on building a environment where BigQuery's analytics can be extended to include data from a production Cloud SQL for PostgreSQL database. Through a rigorous challenge lab, you'll gain hands-on experience in configuring federated connections, implementing role-based security, and validating integration by comparing query execution plans.

## Configure Federated Connections for BigQuery and Cloud SQL for PostgreSQL

In this module, you will concentrate on integrating Google BigQuery with Cloud SQL for PostgreSQL to expand your data analytics capabilities. The module features a challenge lab where you will set up and configure a Cloud SQL for PostgreSQL instance, establish a federated connection with BigQuery, and validate the integration by comparing query execution plans. This will ensure efficient and seamless data access and analytics across both platforms.

### Lab - [Configure Federated Connections for BigQuery and Cloud SQL for PostgreSQL: Challenge Lab](https://partner.skills.google/course_templates/1156/labs/630209)

This challenge lab builds a proof of concept environment that provides access to a production Cloud SQL PostgreSQL database by extending the BigQuery-based analytics reporting environment.
