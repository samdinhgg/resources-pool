## Implement Google Cloud Security Solutions

This module consists of a series of advanced-level labs designed to validate your proficiency in enterprise security. Each lab presents a set of the required tasks that you must complete with minimal assistance.

### Lab - [[PTPPF]: Service Accounts - Operation and Impersonation](https://partner.skills.google/course_templates/1094/labs/551886)

This lab focuses on Service Accounts Operation and Impersonation. You will need to perform service account impersonation to access the credentials of a service account.

- [ ] [[PTPPF]: Service Accounts - Operation and Impersonation](../labs/[PTPPF]-Service-Accounts-Operation-and-Impersonation.md)

### Lab - [[PTPPF]: Secure Access to GKE Workloads with Workload Identity](https://partner.skills.google/course_templates/1094/labs/551887)

This lab focuses on deploying and configuring GKE with workload identity enabled. You will need to configure an application to use workload identity.

- [ ] [[PTPPF]: Secure Access to GKE Workloads with Workload Identity](../labs/[PTPPF]-Secure-Access-to-GKE-Workloads-with-Workload-Identity.md)

### Lab - [[PTPPF]: Security Command Center Investigation and Remediation](https://partner.skills.google/course_templates/1094/labs/551888)

This lab focuses on the Security Command Center, Google Cloud's centralized vulnerability and threat reporting service. You will need to identify and remediate misconfigurations, vulnerabilities, and threats, as well as generate a compliance report.

- [ ] [[PTPPF]: Security Command Center Investigation and Remediation](../labs/[PTPPF]-Security-Command-Center-Investigation-and-Remediation.md)

### Lab - [[PTPPF]: Securing Applications with Google Cloud Armor and Firewall Rules](https://partner.skills.google/course_templates/1094/labs/551889)

This lab focuses on Securing Applications with Google Cloud Armor and Cloud Firewall. You will need to configure firewall rules and Cloud Armor security policies to secure applications on Google Cloud.

- [ ] [[PTPPF]: Securing Applications with Google Cloud Armor and Firewall Rules](../labs/[PTPPF]-Securing-Applications-with-Google-Cloud-Armor-and-Firewall-Rules.md)

### Lab - [[PTPPF]: Cloud Key Management and Raw Encryption](https://partner.skills.google/course_templates/1094/labs/551890)

This lab focuses on key management and data security. You will need to share data securely by using Cloud Key Management Service (KMS) and raw encryption.

- [ ] [[PTPPF]: Cloud Key Management and Raw Encryption](../labs/[PTPPF]-Cloud-Key-Management-and-Raw-Encryption.md)
