# [Implement a Landing Zone and Observability](https://partner.skills.google/course_templates/1573)

**Description:**

In this course, you will learn how to architect, secure, and operate a production-ready Google Cloud environment. Moving beyond basic infrastructure deployment, you will utilize Infrastructure as Code modules to untilize best practices and automate the creation of a secure Landing Zone establishing the necessary projects, networks, and IAM hierarchies with consistency and speed.

You will ensure operational excellence by defining baseline guardrails, such as quotas and log retention policies, and configuring automated alerts to detect security and configuration violations immediately. Finally, you will implement full-stack observability by creating custom dashboards in Cloud Monitoring and instrumenting your Virtual Machines and applications with Cloud Ops agents and OpenTelemetry. By the end of this course, you will have the skills to build a cloud foundation that is not only secure by default but also fully observable.

## Create a Landing Zone and Harden it with Security Command Centre: Challenge Lab

In this lab, you deploy a secure, production-ready landing zone using the Google Cloud foundation - the fundamental bedrock of your environment that establishes the necessary resource hierarchy, security guardrails, and network architecture before you even deploy an application.

To build this, you utilize Terraform as your 'infrastructure as code' engine. You will configure a Shared VPC with Private Google Access and a VM instance using Google best practice modules; these are pre-packaged Terraform code blocks that automate the deployment to ensure your infrastructure is consistent, repeatable, and adheres to Google's architectural standards without manual error.

Additionally, you enforce security best practices, such as blocking serial ports and denying external IP addresses, and enable Security Command Center to monitor the environment
