# [Implement Cloud Networking Solutions](https://partner.skills.google/course_templates/1092)

**Description:**

This Networking course consists of a series of advanced-level labs designed to validate your proficiency in managing a customer's network using Google Cloud services. Each lab presents a set of the required tasks that you must complete with minimal assistance.

## Implement Cloud Networking Solutions

This module consists of a series of advanced-level labs designed to validate your proficiency in managing a customer's network using Google Cloud services. Each lab presents a set of the required tasks that you must complete with minimal assistance.

### Lab - [[PTPPF]: Configure Global external Application Load Balancer with an Unmanaged Instance Group Backend](https://partner.skills.google/course_templates/1092/labs/551881)

This lab focuses on creating a highly available, secure load-balancer on Google Cloud. You will need to configure Google Cloud external HTTPS Load Balancing to expose web applications to the public internet.

- [ ] [[PTPPF]: Configure Global external Application Load Balancer with an Unmanaged Instance Group Backend](../labs/[PTPPF]-Configure-Global-external-Application-Load-Balancer-with-an-Unmanaged-Instance-Group-Backend.md)

### Lab - [[PTPPF]: Detect and Mitigate Attacks Against Cloud Load Balancing Workloads Using Cloud Armor](https://partner.skills.google/course_templates/1092/labs/551882)

This lab focuses on protecting applications and websites against denial-of-service and web attacks. You will need to configure various capabilities in Cloud Armor, setup Cloud CDN, and configure monitoring alerts.

- [ ] [[PTPPF]: Detect and Mitigate Attacks Against Cloud Load Balancing Workloads Using Cloud Armor](../labs/[PTPPF]-Detect-and-Mitigate-Attacks-Against-Cloud-Load-Balancing-Workloads-Using-Cloud-Armor.md)

### Lab - [[PTPPF]: Private Service Connect and Cloud DNS routing policies](https://partner.skills.google/course_templates/1092/labs/551883)

This lab focuses on Private Service Connect and Cloud DNS routing policies. You will need to connect to services within another VPC network using Private Service Connect endpoints and then set up a multi-region failover using Cloud DNS routing policies.

- [ ] [[PTPPF]: Private Service Connect and Cloud DNS routing policies](../labs/[PTPPF]-Private-Service-Connect-and-Cloud-DNS-routing-policies.md)

### Lab - [[PTPPF]: Deploy Palo Alto Networks VM-Series Next-Generation Firewalls in Google Cloud](https://partner.skills.google/course_templates/1092/labs/551884)

This lab focuses on using Palo Alto appliances to manage outbound traffic. You will need to create a virtual private cloud (VPC) network and deploy load balanced Palo Alto Networks VM-Series firewalls to sit in line with outbound traffic

- [ ] [[PTPPF]: Deploy Palo Alto Networks VM-Series Next-Generation Firewalls in Google Cloud](../labs/[PTPPF]-Deploy-Palo-Alto-Networks-VM-Series-Next-Generation-Firewalls-in-Google-Cloud.md)

### Lab - [[PTPPF]: Deploy a Secure Web Proxy Instance with TLS Inspection](https://partner.skills.google/course_templates/1092/labs/551885)

This lab focuses on deploying and configuring Secure Web Proxy for securing web traffic and TLS inspection. You will need to create a VPC network and subnet and configure a Secure Web Proxy with TLS inspection to secure egress web traffic.

- [ ] [[PTPPF]: Deploy a Secure Web Proxy Instance with TLS Inspection](../labs/[PTPPF]-Deploy-a-Secure-Web-Proxy-Instance-with-TLS-Inspection.md)
